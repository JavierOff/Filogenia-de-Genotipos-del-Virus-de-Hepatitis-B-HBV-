# Filogenia-de-Genotipos-del-Virus-de-Hepatitis-B-HBV-
En este nuevo proyecto, quise replicar un flujo de trabajo real de virología molecular: obtener secuencias públicas, compararlas y visualizar sus relaciones evolutivas. Elegí HBV porque su genoma es pequeño (~3.2 kb), y porque sus genotipos son un caso clásico de estudio en epidemiología molecular.
